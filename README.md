# Predicción de Energía de Adsorción mediante MLP

Proyecto de aprendizaje automático para predecir la energía de adsorción utilizando una red neuronal Perceptrón Multicapa (MLP).

## Lenguaje de programación

Python 3.11

## Bibliotecas utilizadas

- TensorFlow
- Scikit-Learn
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook
  
## Contenido

- Modelo entrenado (`modelo_nanotubo.keras`)
- Métricas de evaluación
- Gráficas de entrenamiento y validación

## Métricas obtenidas

- R² = 0.9767
- MAE = 0.6144
- MSE = 0.5492
- RMSE = 0.7411

## Archivos generados

- curva_perdida.png
- curva_mae.png
- real_vs_predicho.png
- predicciones_modelo.csv
